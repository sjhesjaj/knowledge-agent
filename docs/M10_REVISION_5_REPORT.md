## 2. P1：命题是否在肯定这个数

### 复现（修复前）

在验收方冻结的第四轮候选副本上跑本轮复现脚本，四例全部 `(True, ok)`，两接口原样
发送并落库，**每侧只用一次生成**（连预设的正确复查都用不上）：

```text
公司规定的年假确实是你说的99天。[来源1]
你说的99天就是公司规定的年假额度。[来源1]
正式员工并不是没有99天带薪年假。[来源1]
你说的99天和原文的5天相比，前者才对。[来源1]
```

### 根因

上一轮问的是"有没有词管得到这个数"。**管得到不等于没在断言。** 前三句里 `你说的`
确实管到了 99，但归属只说明这个数出自提问者——完全不妨碍句子自己再肯定它。
于是判定退化成"找到一个沾边的词、又没在有限范围里命中背书词，就放行"，默认值站错了边。

复验点出的四个漏检原因（肯定在前、等同表达、否定被否定、背书指向前一个数）看似四件事，
其中三件同一个根：**归属不该有豁免权**。

### 修复

**（1）归属降级为轻modifier。** `_ATTRIBUTION_MODIFIERS`（`你说的`、`按你`、
`按你提供的`…）从豁免词表移入 `_LIGHT_MODIFIERS`：它不引入新对象，所以
`不是你说的99天`、`如果按你说的99天计算` 这些**真的**由否定或条件撑住的说法照旧成立；
但它自己什么也豁免不了。这一处同时解决了反例 1、2、4——不必去数背书词落在数值哪一侧，
也不必给"就是"再补一个词。

豁免词只剩两类：**否定**与**条件**。

**（2）否定词自己也可能被否定。** `_denies()` 检查：这个否定词前面，是否还有另一个
否定词管得到它。`并不是没有99天` 是双重否定，等于肯定，因此不豁免。只看一层——
三重否定这种拿不准的嵌套一律不豁免。

**（3）否定也允许紧跟在数值后面。** `你说的99天并不正确` 里的否定在数值右边，中间
只隔着轻modifier 才算数；`99天带薪年假没有特殊限制` 里那个 `没有` 中间隔着"带薪年假"，
够不着。范围同样到下一个数值为止。

背书规则（`_ENDORSEMENT_PATTERN`，到下一个数值为止）保留：归属降级后它不再负责反例
1/2/4，但仍守住"先否定、后又肯定同一个数"，见第 6 节的对照测试。

### 修复后

| 反例 | 语义 | 结果 |
|---|---|---|
| 公司规定的年假确实是你说的99天 | 肯定在数值前 | 拦截 ✔ |
| 你说的99天就是公司规定的年假额度 | 等同判断 | 拦截 ✔ |
| 正式员工并不是没有99天带薪年假 | 双重否定＝肯定 | 拦截 ✔ |
| 你说的99天和原文的5天相比，前者才对 | 背书指向前一个数 | 拦截 ✔ |

| 正例 | 结果 |
|---|---|
| 不是99天而是5天带薪年假。[来源1] | 交付 ✔ |
| 如果按你说的99天计算，结论仍需核对原文。[来源1] | 交付 ✔ |
| 不是99天。5天才对。[来源1] | 交付 ✔ |

### 变体（每次只改一样东西，期望按证据与句义判定，不照抄函数输出）

| 变体族 | 覆盖 | 结果 |
|---|---|---|
| 数值替换（问句同步替换） | 99 / 88 / 30 / 7 / 120 × 7 种句式 = 35 例 | 全部符合 ✔ |
| 确认语前后移动 | 数值前 / 数值后 / 句首 / 句尾 4 例 | 全拦 ✔ |
| 否定一次 vs 否定该否定 | `没有99天`(放) / `并不是没有99天`(拦) / `不是没有99天`(拦) / `并不是不是99天`(拦) | 全部符合 ✔ |
| 两数值顺序与前者/后者 | `99…5…前者才对`(拦) / `5…99…后者才对`(拦) / `不是99天。5天才对`(放) / `5天才对，不是99天`(放) | 全部符合 ✔ |

## 3. P2：只有纯拒答才免引用

### 复现（修复前）

```text
根据现有资料无法确定奖金金额。正式员工入职满一年后每年享有5天带薪年假。

validate_answer(...) = (True, 'refusal')
两接口各 2 次调用后原样发送、正常 done、落库
```

数量 5 有依据，但那句事实断言**没有来源标注**，而且整段不是纯拒答。

### 根因

`is_refusal()` 是整段子串匹配，`not refusal` 于是让任何含拒答短语的答案都跳过
`no_citation`。拒了一件事，不等于后面那句也不用给依据。

（上一轮"含拒答词就不查无依据数量"的修复**保留**——那是另一条路径，第 6 节仍有
撤销测试守着。）

### 修复

新增 `is_pure_refusal()`：按句号/问号/感叹号/换行切句，**每一句都拒答**才算纯拒答。
免引用的资格从"出现过拒答短语"改成"整段没有别的断言"。逗号不算句子边界——
`资料没写，无法确定` 是一句话。

```python
if results and not is_pure_refusal(answer_text) and not citation_indices(answer_text):
    return False, "no_citation"
```

### 修复后

| 输出 | 结果 |
|---|---|
| `根据现有资料无法确定奖金金额。……每年享有5天带薪年假。`（无引用） | `(False, no_citation)`，两接口交付统一拒答 ✔ |
| 同上 **加 `[来源1]`** | 交付 ✔ |
| `根据现有资料无法确定。` | `(True, refusal)`，不要求引用 ✔ |
| `根据现有资料无法确定奖金金额。` | 交付 ✔ |
| `根据现有资料无法确定奖金金额。也无法确定年假天数。` | 交付 ✔ |
| `根据现有资料无法确定奖金金额。……每年享有99天……[来源1]` | `(False, ungrounded_quantity)`，上一轮的修复未被影响 ✔ |
