## 3. P1：后置否定必须在否定这个说法

### 复现（修复前）

```text
正式员工每年休99天没有问题。[来源1]        validate=(True, ok)   两接口 1 次生成即交付并落库
正式员工每年休99天没有额外限制。[来源1]    validate=(True, ok)   同上
```

首轮被判为可交付，所以**连既有的那次复查都不会触发**——即使预设第二次响应是正确的
5 天也用不上。

### 根因

第五轮我加的分支是这样写的：

```python
for position in _cue_positions(trailing, _DENIAL_CUES):
    if _governs(trailing[: position[0]]) and not _denies(trailing, position[0]):
        return True
```

它只检查**数值到否定词之间**有没有东西。否定词紧贴数值时中间为空，`_governs("")`
为真，于是「否定问题」「否定限制」都成了「否定 99 天」。

相邻不等于在说这件事。`99天没有问题` 与 `99天并不正确` 里的否定词都紧挨着数值，
差别全在**否定的是什么谓语**——前者否定「问题」，整句在肯定可以休 99 天。

### 修复

后置豁免改为要求一个**驳斥谓语**：明确否定这个说法本身或其正确性。

```python
_REFUTATION_PATTERN = re.compile(
    r"并?不(?:正确|准确|属实|成立|符合事实|是这样|对(?![外内]))"
    r"|并非(?:如此|事实|属实)"
    r"|(?:说法)?有误|是错的|站不住脚|不足为据"
)
```

`不对` 排除 `不对外`/`不对内`——那是「不面向」，不是「不正确」。数值与驳斥谓语之间
仍要求只隔轻modifier（`说法` 一并加入轻modifier，`99天这个说法并不准确` 才成立），
范围同样到下一个数值为止。

**没有**用「排除 `问题`、`额外限制` 两个名词」的特判，也没有再把任意紧邻否定当成
数值否定；识别不了的表达一律不豁免，落回既有复查/拒答。

### 修复后

| 答案 | 否定的对象 | 结果 |
|---|---|---|
| `99天没有问题` | 问题 | 拦截 ✔ |
| `99天没有额外限制` | 限制 | 拦截 ✔ |
| `99天没有障碍` / `没有任何门槛` | 障碍 / 门槛 | 拦截 ✔ |
| `99天不对外公开` | 不是驳斥 | 拦截 ✔ |
| `你说的99天并不正确，原文写的是5天` | 这个说法 | 交付 ✔ |
| `你说的99天不对 / 有误 / 这个说法并不准确` | 同上 | 交付 ✔ |
| `正式员工每年休5天没有问题。[来源1]` | 同一句式，数量有依据 | 交付 ✔ |

## 4. P2：纯拒答要覆盖整段含义

### 复现（修复前）

以下三例数量有依据但**没有引用**，且都不是纯拒答，却被判为 `(True, refusal)`：

```text
根据现有资料无法确定奖金金额，但正式员工入职满一年后每年享有5天带薪年假。
根据现有资料无法确定奖金金额；正式员工入职满一年后每年享有5天带薪年假。
正式员工入职满一年后每年享有5天带薪年假，但根据现有资料无法确定奖金金额。
```

### 根因

第五轮的 `is_pure_refusal()` 按句号/问号/感叹号切片，再对每片做**子串匹配**。
只要把句号换成逗号、分号或"但"，那句事实断言就和拒答挤进同一片，整段又被当成纯拒答。
「每片含拒答词」不等于「整段没有事实断言」。

### 修复

两条都不是「把逗号补进分隔正则」：

1. 改用**断言边界** `_ASSERTION_SPLIT`（标点**加上** `但/而是/不过/并且` 这类连接词）；
2. 每个断言段不仅要含拒答短语，还必须**没有在拒答之前断言数量**——先给结论再说
   查不到，同样不是纯拒答。

```python
for segment in segments:
    marker = _refusal_marker_index(segment)
    if marker is None:
        return False                      # 这一段没在拒答，它是一句事实
    if any(m.start < marker for m in quantity_mentions(segment)):
        return False                      # 先断言数量、再说查不到
```

### 修复后

| 文本 | 结果 |
|---|---|
| 三个混合反例（逗号/分号/句号/`而`/`不过`，两种顺序） | `(False, no_citation)`，两接口交付统一拒答 ✔ |
| 同一混合回答**加 `[来源1]`** | 交付 ✔ |
| `根据现有资料无法确定。` | 交付，不要求引用 ✔ |
| `根据现有资料无法确定奖金金额，也无法确定补贴标准。` | 交付（逗号连接的纯拒答）✔ |
| `每年5天年假，具体天数无法确定。` | 非纯拒答（数量在拒答之前）✔ |
| `……，但正式员工每年享有99天带薪年假。[来源1]` | `(False, ungrounded_quantity)`，第四轮的修复未受影响 ✔ |
