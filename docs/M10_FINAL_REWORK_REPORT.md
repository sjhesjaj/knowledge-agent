## 2. 本轮修复的两处绑定机制

### 2.1 前提绑定：函数原先根本没收到问句

**复现（修前）**：来源只有每年 5 天年假。

| 问句 | 被交付的错误正文 | 说明 |
|---|---|---|
| 我在公司工作了99天，请介绍正式员工年假政策。 | 你的年假是99天。[来源1] | 旧残留 |
| 我的年假是99天吗？请核对原文。 | 你的年假是99天。[来源1] | **我引入的回归** |
| 我的报销单金额是2500元，请说明审批规则。 | 这笔2500元就是公司统一的报销审批分界线。[来源1] | 旧残留 |

三条都是两接口直接发出并落库、各 1 次调用，预置的正确复查根本没机会执行。

**根因**：`_is_premise_restatement()` 只拿到答案、数值位置和断言起点，
**没有问句，也没有问句里对应的那一次出现**。它实际在做的是"答案附近没命中政策词、
又出现了`你的/这笔`，就豁免"——人称词只说明在讲谁，证明不了两边说的是同一件事。

**修复**：三条信息缺一不可。

1. **问句的这一次出现是给定前提还是待核实主张**（`_question_occurrence_is_given`）。
   按**该数值所在分句**判断：`我的年假是99天吗` 的 `吗` 就贴在这个数上 → 待核实；
   `这笔报销费用为2500元，是否需要部门负责人审批？` 的 `是否` 在下一个分句，
   问的是审批要不要 → 2500 仍是给定前提。
2. **答案的这一次出现是不是在替资料发言**（`_POLICY_VALUE_MARKERS`）。
3. **两边是不是同一个属性**——比对**分词后的实词**，不是字面重合。

**为什么用分词**：`我的报销单金额是2500元` 与
`这笔2500元就是公司统一的报销审批分界线` 共有一个 `报销` 字面，二字组会判成同一对象；
分词把它们切成 `报销单/金额` 与 `公司/统一/报销/审批/分界线`，属性词就对不上了。
这是把判据换成词一级的对应，不是给政策词表补 `分界线`。

**逐条对应关系**（按要求写明"问句哪次出现 ↔ 答案哪次出现"）：

| 问句出现（属性词） | 答案出现（属性词） | 判定 |
|---|---|---|
| `我在公司工作了99天` → `公司/工作` | `你的年假是99天` → `年假` | 属性不符 → **拦截** |
| `我的年假是99天吗` → 待核实主张 | `你的年假是99天` | 非给定前提 → **拦截** |
| `我的报销单金额是2500元` → `报销单/金额` | `这笔2500元就是…分界线` → `公司/统一/报销/审批/分界线` | 属性不符 → **拦截** |
| `这笔报销费用为2500元` → `这笔/报销/费用`（给定） | `这笔2500元报销需要部门负责人审批` → `这笔/报销/需要` | 同属性 → **放行** |
| `单笔 2500 元的报销`（给定） | `单笔2500元的报销需要部门负责人审批` | 同属性 → **放行** |

历史的 99 天核对题在第 1 步就判为"待核实"，仍由既有否定/驳斥路径处理，
`不是99天而是5天` 等正例不受影响。

**中途弯路（如实记）**：我先试过"与问句同一数值的上下文有实词重合"作为第二条判据，
结果 47 项测试变红——`公司规定的99天不对5天内入职的员工公开` 因为碰巧共有一个
`入职` 就被当成复述前提。**词面重合证明不了是同一个东西**，那条被删掉而不是调参。

### 2.2 编号扫描：宽松匹配把未知家族整个漏掉了

**复现（修前）**：来源 `SKU-C300 的当前库存为7箱`。

| 错误正文 | 原因 | |
|---|---|---|
| `SPU-C300 当前库存7箱。[来源1]` | 已知家族只有 `sku`，`SPU` 整个被忽略 | **我引入的回归** |
| `sku  c30 当前库存7箱。[来源1]` | 两个空格不符合"单个可选分隔符"，整串未提取 | 旧残留 |
| `SKU-C300A 当前库存7箱。[来源1]` | 只提取到 `SKU-C300`，尾部 `A` 被丢掉 | 旧残留 |

**根因**：我把"已知家族的宽松写法"当成了**唯一**的扫描式。放宽书写形式，
反而放过了另一个实体。

**修复**：两式并行，比较**完整标识**。

- **显式标识**（家族无关）：字母前缀 + 硬分隔符 + 尾部，尾部把后面粘着的字母数字
  一并吃掉。`SPU-C300` 写得明明白白是编号，证据里没有就拦下；`SKU-C300A` 整串提取，
  不会被截成已知的 `SKU-C300`。
- **已知家族的宽松写法**：只用来允许**合法书写变体**（空格可多个、可无分隔符）。

**完整提取出的编号**（按要求写明）：`SPU-C300`、`sku  c30`、`SKU-C300A` 分别被完整
提取并归一为 `spuc300`、`skuc30`、`skuc300a`，都不等于证据里的 `skuc300`。
`SKU-C300`／`sku c300`／`SKU  C300`／`skuc300` 归一后相等，正常交付。
`GB18030`、`ISO 8601` 没有硬分隔符，不是业务标识，不受影响。

- **前提绑定**：证明不了"同一属性"就不豁免。模型换个说法复述前提
  （如不带指代词的 `2500元的报销需要部门负责人审批`）会被保守拦下，再由复查挽回。
- **驳斥表**：只认 `不对`、`有误`、`并不正确` 等有限结构；表外说法
  （`99天这个数字与原文对不上`）走保守拒答。
- **拒答主题**：只认有限名词表；表外主题（`各地区差旅补助口径`）不算纯拒答，要引用。
- **已知误拒**：`不是公司规定的99天，原文写的是5天。[来源1]`——`不是` 与 99 之间
  隔着 `公司规定的`，无法判断那是定语还是 `不是` 自己的宾语。自第四轮起未变。

0% / 5% / 5%。
