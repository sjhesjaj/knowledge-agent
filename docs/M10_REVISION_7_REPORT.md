## 3. P1：驳斥必须是完整表达

### 复现（修复前）

```text
公司规定的99天不对第三方公开。[来源1]      validate=(True, ok)   两接口 1 次生成即交付并落库
正式员工每年休99天有误工补贴。[来源1]      validate=(True, ok)   同上
```

首轮被判可交付，所以**连既有那次复查都不触发**——预设第二次响应是正确的 5 天也用不上。

### 根因

第六轮我只写了一张驳斥词表，没有检查**匹配的尾部**：

- `不对第三方公开` 是"不向第三方披露"，`不对` 只是它的前缀；
- `有误工补贴` 是"存在误工补贴"，`有误` 只是它的前缀。

给 `不对` 再排除几个宾语、给 `有误` 排除一个 `工` 字是补不完的——问题不在漏了哪个词，
在于**没检查后面还接着什么**。

### 修复

驳斥必须以**句读或句末**收尾（允许中间夹一两个语气词）。这条边界是可说明的：匹配之后
要么什么都没有了，要么只剩标点；只要还接着别的字，就说明这几个字是更长的词或另一个
谓语的一部分，不能据此豁免。

```python
_REFUTATION_PATTERN = re.compile(
    r"(?:" + _REFUTATION_CORE + r")"
    r"[吧呢啊呀了的]{0,2}"
    r"(?=$|[\s，,。；;：:！？!?、\n])"
)
```

`(?![外内])` 那个临时排除**已经删掉**——有了尾部边界就不需要它，`不对外公开` 自然
不再匹配。这是把特判换成了结构，不是又加一条特判。

### 修复后

| 答案 | 尾部 | 结果 |
|---|---|---|
| `99天不对第三方公开` | `第…` | 拦截 ✔ |
| `99天不对外披露` | `外…` | 拦截 ✔ |
| `99天有误工补贴` | `工…` | 拦截 ✔ |
| `99天有误差范围` | `差…` | 拦截 ✔ |
| `你说的99天不对，原文写的是5天` | `，` | 交付 ✔ |
| `你说的99天不对。` | 句末 | 交付 ✔ |
| `你说的99天不对吧，……` | 语气词＋`，` | 交付 ✔ |
| `你说的99天有误 / 并不正确 / 并不准确 / 不属实，……` | `，` | 交付 ✔ |

第六轮修好的 `99天没有问题`、`99天没有额外限制`、`99天没有障碍` 仍然拦截。

## 4. P2：纯拒答改为正向判定

### 复现（修复前）

两种无引用输出仍被判为 `(True, refusal)`：

```text
奖金金额无法确定而正式员工入职满一年后每年享有5天带薪年假。
正式员工享有带薪年假这点已确定只是奖金金额无法确定。
```

### 根因

前两轮都是**反向**判的：先假定整段在拒答，再找理由推翻——上上轮找"跨句号的事实"，
上一轮加"拒答词之前有没有数量"。反向判定永远漏一种写法：第一例的数量在拒答**之后**
且 `而` 不是断言分隔符；第二例被肯定的事实**根本没有数字**，数量检查看不见它。

继续往连接词表里加 `而`、`只是` 只会等下一种写法。方向错了，不是词不够。

### 修复

改成**正向**：整段必须能被拒答子句一段一段地解释干净，有一个字没被解释就没有资格。

```text
    [根据现有资料][也/暂时][奖金金额] 无法确定 [奖金金额] [，。；]
     └ 证据范围 ┘ └ 副词 ┘ └ topic ┘  └ 谓语 ┘ └ about ┘
```

`topic`/`about` 是有界的短片段（不跨标点、长度受限），而且**不能自带断言**：带数量或
带 `而/但/只是/已确定/享有` 这类词的片段一律不算主题（`_carries_assertion`），
免得一条短尾巴把事实吞进"拒答主题"。

事实排在拒答前面还是后面、带不带数字，都不属于任何一条拒答子句，因此都拦得住。

### 修复后

| 文本 | 结果 |
|---|---|
| `奖金金额无法确定而……5天带薪年假。` | `(False, no_citation)` ✔ |
| `……5天带薪年假而奖金金额无法确定。` | `(False, no_citation)` ✔ |
| `……这点已确定只是奖金金额无法确定。` | `(False, no_citation)` ✔ |
| `奖金金额无法确定只是……这点已确定。` | `(False, no_citation)` ✔ |
| 以上任一**加 `[来源1]`** | 交付 ✔ |
| `无法确定奖金而年假5天成立。` | 非纯拒答（主题里藏了断言）✔ |
| `根据现有资料无法确定。` / `奖金金额无法确定。` / `暂时无法确定奖金金额。` | 免引用交付 ✔ |
| `根据现有资料无法确定奖金金额，也无法确定补贴标准。`（逗号/分号两种） | 免引用交付 ✔ |
| `原文中未提及奖金金额。` / `资料不足，无法确定。` / `资料中没有相关记录，无法确定。` / `根据资料无法回答这个问题。` | 免引用交付 ✔ |
| `……无法确定奖金金额。……每年享有99天带薪年假。[来源1]` | `(False, ungrounded_quantity)`，第四轮的修复未受影响 ✔ |

## 10. 残余问题与未完成验证

### 10.1 已知的保守误拒

| 仍误拒 | 为什么识别不了 |
|---|---|
| `不是公司规定的99天，原文写的是5天。[来源1]` | `不是` 与 99 之间隔着 `公司规定的`，无法判断那是 99 的定语还是 `不是` 自己的宾语 |

已写成测试钉住。24 个历史合法措辞本轮全部首轮放行，这一条不在其中——它是第四轮起就
记录的同一条限制，本轮没有改善也没有恶化。

### 10.2 两处豁免的结构边界（会误拒什么，说清楚）

- **驳斥**：必须是列出的那几种说法，且以句读或句末收尾。模型若写
  `99天这个数字与原文对不上`、`99天的说法站不住脚吧我觉得`（尾部还接着别的字），
  都不豁免，走保守拒答。
- **纯拒答**：整段必须被 `_REFUSAL_CLAUSE` 解释干净，主题片段有长度上限且不能带数量或
  转折词。因此 `无法确定每年5天年假是否属实` 这类**在拒答主题里带数字**的写法会被判为
  需要引用；`根据我们上周同步过的口径，奖金金额无法确定` 这类超长前缀也会。
  两者都落到"需要引用"一侧——保守，方向安全，但确实是误拒。

这两段边界是有意画窄的：**未知结构默认不豁免**。代价记录在此，不用一律拒答来制造
接口一致。

### 10.3 定向计数不是真实误拒率

本报告的 24/24、10/10 等都是**定向措辞样本**在确定性路径上的首轮判定，
**不能换算成真实模型的 False Refusal Rate**。首轮被拦的答案还可能由既有的那一次复查
救回；真实指标须由后续三轮回答评测得到。
